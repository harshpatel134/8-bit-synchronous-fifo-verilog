# Simulation Results

The FIFO was simulated using ModelSim.

## Verification Tests

The testbench verifies:

- Reset operation
- FIFO write operation
- FIFO full condition
- FIFO read operation
- Data integrity
- FIFO empty condition
- Simultaneous read/write operation

## Results

All eight stored data values were successfully read back and verified.

The simulation completed successfully without verification errors.

## Waveforms

The waveform screenshots show the clock, reset, read/write controls, input/output data, full flag, and empty flag during simulation.
